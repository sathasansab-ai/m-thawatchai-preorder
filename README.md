# ⚡ ระบบเว็บไซต์ PRE-ORDER เสื้อสตรีท "เอ็ม ธวัชชัย" (M Thawatchai Official)

ระบบเว็บลงทะเบียนสั่งจองสินค้า Pre-order สไตล์สตรีทแวร์ พร้อมระบบชำระเงิน ตรวจสลิป เช็คสถานะด้วยเบอร์โทร สรุปยอดตัดเย็บโรงงาน และพิมพ์ใบปะหน้าพัสดุพร้อมรายการแพ็คของ

---

## 📁 โครงสร้างไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่และความสำคัญ |
|---|---|
| 🌐 **`index.html`** | หน้าร้านค้าหลัก: สตรีทแวร์ Dark Mode, โมเดลเสื้อ Interactive ซูมดูเนื้อผ้า/สกรีน, ปุ่มฟังเสียงเล่าเรื่องจากเอ็ม, ฟอร์มเลือกสี/ไซส์, ค้นหารหัสไปรษณีย์อัตโนมัติ, พร้อมเพย์ QR Code และอัปโหลดสลิป |
| 🔍 **`tracking.html`** | หน้าเช็กสถานะพัสดุด้วยเบอร์โทร (Self-Service Tracking): ลูกค้ากรอกเบอร์โทรดูสถานะได้ทันที (รอตรวจสลิป / กำลังผลิต / จัดส่งแล้วพร้อมเลขแทร็กกิ้ง) |
| 🛡️ **`admin.html`** | หน้าแดชบอร์ดหลังบ้าน: ล็อคอินด้วย PIN, สรุปยอดขาย, ตาราง Production Matrix แยกไซส์/สีเพื่อส่งโรงงาน, ตรวจสลิป, ใส่เลขพัสดุ, Export CSV และพิมพ์ใบปะหน้า |
| ⚙️ **`config.js`** | ไฟล์ตั้งค่าส่วนกลาง: เบอร์พร้อมเพย์, เลขบัญชีธนาคาร, ชื่อบัญชี, ราคาเสื้อ, ค่าจัดส่ง, ที่อยู่ผู้ส่ง, รหัส PIN แอดมิน และค่า Supabase |
| 📍 **`thai-address.js`** | ฐานข้อมูลและระบบ Autocomplete รหัสไปรษณีย์ไทย 5 หลัก (ดึงตำบล อำเภอ จังหวัด อัตโนมัติใน 0.1 วินาที) |
| 🗄️ **`supabase-schema.sql`** | สคริปต์ SQL สำหรับสร้างตาราง `orders`, `order_items` และ Storage Bucket ใน Supabase |

## 🚀 วิธีเปิดใช้งานและทดสอบระบบทันที

1. **เปิดหน้าเว็บลูกค้า:**
   * ดับเบิ้ลคลิกเปิดไฟล์ **`index.html`** ด้วย Google Chrome หรือ Microsoft Edge หรือเบราว์เซอร์ใดก็ได้
   * ทดสอบเลือกสี (ดำ/ขาว) คลิกปุ่มซูมขยายดูเนื้อผ้า
   * ทดสอบกดปุ่ม **"ฟังเรื่องราวของเสื้อตัวนี้จากเสียงของเอ็ม"**
   * ทดสอบพิมพ์รหัสไปรษณีย์ เช่น `10110` หรือ `50000` ระบบจะดึงจังหวัด/อำเภอ/ตำบล ให้อัตโนมัติ
   * กดส่งออเดอร์เพื่อทดสอบการบันทึก

2. **ทดสอบระบบเช็คสถานะ:**
   * เปิด **`tracking.html`** แล้วกรอกเบอร์โทรที่สั่งจอง เพื่อดูแถบไทม์ไลน์สถานะพัสดุ

3. **เข้าสู่ระบบแอดมิน (Admin Portal):**
   * เปิด **`admin.html`**
   * กรอกรหัส PIN: **`1234`** (สามารถเปลี่ยนได้ใน `config.js`)
   * ดูตาราง **Production Matrix** สำหรับส่งยอดตัดเย็บให้โรงงาน
   * ตรวจดูรูปสลิปขนาดใหญ่ และกดยืนยันยอดเงิน
   * กดปุ่ม **"ใบปะหน้า"** เพื่อทดสอบพิมพ์สติกเกอร์ขนส่งความร้อน (100x150 มม.) ซึ่งจะมี **รายการของที่ต้องแพ็ค** พิมพ์ตัวหนาอยู่ด้านล่างสุด เช่น `[ดำ-L x 1] [ขาว-XL x 2]` ทีมงานแพ็คของได้ทันทีไม่ต้องสลับจอ

## ☁️ วิธีเชื่อมต่อฐานข้อมูล Supabase Cloud (เมื่อพร้อมขึ้นระบบจริง)

1. สมัครหรือเข้าสู่ระบบที่ [https://supabase.com](https://supabase.com)
2. สร้างโปรเจกต์ใหม่ (New Project)
3. ไปที่เมนู **SQL Editor** ใน Supabase แล้วเปิดไฟล์ **`supabase-schema.sql`** คัดลอกโค้ดทั้งหมดไปวางแล้วกด **Run**
4. ไปที่ **Project Settings -> API** ใน Supabase คัดลอก `Project URL` และ `anon public key`
5. นำมาใส่ในไฟล์ **`config.js`** ในส่วน:
   ```javascript
   supabase: {
     url: "https://xxxx.supabase.co",
     anonKey: "eyJhbGciOi...",
     storageBucket: "payment_slips"
   }
   ```
6. อัปโหลดไฟล์ทั้งหมดขึ้น Hosting ฟรี เช่น **Vercel, Netlify, Cloudflare Pages หรือ GitHub Pages** เพื่อเปิดให้แฟนคลับสั่งจองได้ทั่วโลกตลอด 24 ชม.!
