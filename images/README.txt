# โฟลเดอร์สำหรับใส่รูปภาพจริง

คุณสามารถนำรูปภาพจริงมาใส่ในโฟลเดอร์นี้ตามชื่อไฟล์ต่อไปนี้:
1. `shirt-black-front.jpg` = รูปเสื้อสีดำ ด้านหน้า
2. `shirt-black-back.jpg`  = รูปเสื้อสีดำ ด้านหลัง
3. `shirt-white-front.jpg` = รูปเสื้อสีขาว ด้านหน้า
4. `shirt-white-back.jpg`  = รูปเสื้อสีขาว ด้านหลัง
5. `my-qr.jpg`             = รูป QR Code ธนาคาร (กรณีต้องการใช้ภาพ QR สแกนจ่ายของตนเอง)

* หากยังไม่มีรูปภาพ ระบบจะมีภาพตัวอย่างสวยงามให้ทดสอบอัตโนมัติครับ
