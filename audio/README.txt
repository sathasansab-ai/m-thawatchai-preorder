# โฟลเดอร์สำหรับใส่ไฟล์เสียงจริงของ เอ็ม ธวัชชัย

นำไฟล์เสียงจริง (เช่น บันทึกจากมือถือ หรือตัดต่อแล้ว) มาบันทึกไว้ที่นี่ในชื่อ:
- `m-voice.mp3`

* เมื่อนำไฟล์มาวางแล้ว ระบบจะเล่นเสียงจริงของเอ็มทันทีเมื่อลูกค้ากดปุ่มฟังเสียงที่หน้าเว็บ!
* หากยังไม่ได้ใส่ไฟล์ ระบบจะมีเสียงพูดจำลองให้อัตโนมัติสำหรับการทดสอบครับ
